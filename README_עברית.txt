MAYA TOURS – INTEL KG | גרסת ניסיון 0.1

זהו פרויקט מקור ל-Android Studio, ולא קובץ APK מוכן.
להפקת APK:
1. פתח Android Studio במחשב.
2. בחר Open ופתח את תיקיית MAYA_TOURS_INTEL_KG.
3. אפשר לסביבת הפיתוח להוריד את Android SDK ו-Gradle לפי הצורך.
4. בחר Build > Build APK(s).
5. קובץ ההתקנה ייווצר בדרך כלל ב-app/build/outputs/apk/debug/app-debug.apk.
6. התקן בטלפון רק לאחר בדיקת מקור הקובץ וההרשאות.

גרסה זו פועלת באופן מקומי בלבד. אין חיבור ענן, ניהול משתמשים אמיתי, התראות או אישור כשירות משפטי/תפעולי.
אין להזין מידע אישי רגיש. אין להשתמש במערכת לקבלת החלטות כשירות רכב בפועל.
למערכת ארגונית יש להוסיף שרת, אימות משתמשים, בקרת הרשאות בצד השרת, גיבוי והיסטוריית ביקורת.
